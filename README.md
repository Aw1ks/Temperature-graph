# Temperature-graph
## APIs and libraries used
**opendatasoft:** To get the coordinates of the city by name and country code.
[Documentation](https://public.opendatasoft.com/explore/)
**open-meteo:** For weather data.
[Documentation](https://open-meteo.com/en/docs)

This project uses libraries such as: [requests](https://python-scripts.com/requests?ysclid=lyr2i4f3us982315000), [pandas](https://pandas.pydata.org/) and [matplotlib](https://matplotlib.org/)
## Usage
1. Run the 'python main.py' script.
2. Enter the name of the city (in English, with a capital letter), the country code (in ISO 3166-1 alpha-2 format, for example, "US"), the start and end date of the period (in the format YYYY-MM-DD).
3. The script will display a graph of temperature changes for the specified city in a given period of time.
